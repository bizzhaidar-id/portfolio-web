1. Export Inland Cost Reduction (SGA 2024, gold medal). Gabungan dari "Transporter Vendor Allocation". Top 1 vendor usage 25% to 53.5%, trucking cost per MT -21%.

3. Export Inland Daily Checker (dibangun dengan AI).
4. Export Inland Trucking Manual Book.
